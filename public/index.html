Реплики кадра:
Как формируются строки

/me → «* Ник[ID] текст» · /do → «* текст (( Ник ))» · Речь → «Ник[ID] сказал: текст». В поле «Вместо глагола» можно написать своё («по телефону», «по рации» → «Ник по телефону: текст»; {глагол} подставит «сказал/сказала»). Поле «Другой ник» задаёт другого персонажа (пусто — основной). Рядом с текстом — цвет конкретной реплики, двойной клик сбрасывает.

Подсказки
СкриншотКнопка «Загрузить скриншот», перетаскивание файла в окно или Ctrl+V. Несколько файлов — несколько кадров. Текст на кадреТащите мышью. Синие квадраты на рамке: правый — ширина, нижний — высота, угловой — масштаб. ФонТащите — сдвиг, колесо мыши — масштаб. Белая рамка — обрезка кадра (можно и расширять). Слой-картинкаТащите — перемещение, угловые квадраты — размер, кружок сверху — поворот (Shift — шаг 15°). Выбор слояКлик по картинке в кадре или в списке слоёв. Прозрачные места «прозрачны» для клика. КлавишиDelete — удалить слой · стрелки — сдвиг на 1 px (Shift — на 10) · Esc — закрыть окно ПолзункиДвойной клик по названию параметра сбрасывает его. ХранениеВсё автоматически сохраняется в вашем аккаунте на сервере и доступно с любого устройства. Резервную копию в файл можно сделать через «Проект».
